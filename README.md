# 量见 · 0.2 开发版

面向量化新手，帮助用户把一个简单的投资想法，变成规则明确、可以验证的策略，
再通过回测等实验与 AI 分析，生成看得懂、有证据的报告。

目标使用流程：**表达想法 → 澄清规则 → 确认策略 → 执行验证 → 阅读报告与证据 → 继续追问**。

## 产品定位与界面规划

用户不需要先了解量化术语或会写策略。产品通过少量引导、可解释的默认设置及逐层展开的
报告，帮助用户完成一次自己能理解的历史验证。

规划四个主模块：

| 模块 | 用途 |
|---|---|
| 首页 | 简介、受支持示例、示例报告和开始验证入口 |
| 使用文档 | 使用流程、默认值与修改影响、报告阅读及 AI 回答模式说明 |
| 量化策略验证 | 想法澄清、策略确认、可选实验、回测、AI 分析与证据报告，作为核心功能 |
| AI 金融问答 | 基本概念、常见量化策略教学、结合当前报告答疑，并引导进入验证 |

以上四个模块已接入同一套 Streamlit 导航。首页提供能力说明与策略入口，使用文档解释流程、
默认值和报告阅读方法，量化策略验证承载完整 Agent 流程，AI 金融问答支持基础概念解释并可把
受支持策略带入验证。
设置分为实验设置和 AI 回答偏好；默认面向新手讲解，修改回答方式不改变实验事实。
金融 skill、MCP 为问答模块的候选实现方式，具体接入方案待细化。
详见 [产品定位与模块规划](docs/product.md)。

> 历史回测不代表未来收益；测试未发现问题不等于策略已被证明有效。本项目仅供学习研究，不构成投资建议。

## 快速开始

```bash
pip install -r requirements.txt
# 可选：部署者可复制 .env.example 为 .env 并填写服务器默认 LLM 配置
# 首次使用：生成模拟快照并执行无 LLM 完整验收；无需 API Key
python scripts/acceptance.py
streamlit run app.py
```

启动后，用户也可以在侧栏展开“模型连接”，填写 API Key、OpenAI 兼容接口 URL、模型名和可选的
报告模型。可以直接保存，也可以先测试连接再保存。前端配置只保存在当前 Streamlit 会话中，
不会写入 `.env`、仓库、报告或下载文件；存在前端配置时，它优先于服务器环境变量。

配置模型后可单独验证兼容接口、自然语言解析和 AI 证据报告：

```bash
python scripts/llm_smoke.py --report
```


## 分工说明

**数据模块（`core/data/`，组员负责）**

- 定义本次支持的 ETF 资产池（标的代码、名称、所属类别），类别会影响质量检查的涨跌停阈值。
- 用户确认标的和区间后，先查询本地真实行情缓存；没有完整覆盖时自动从公开接口拉取日线行情，并把结果写入缓存。
- 统一行情列名和格式，取数失败要抛异常，不能静默返回空表或假数据。
- 对拉到的数据做质量检查：排序去重、缺失交易日、价格异常（只标记不删除）、非正价格、OHLC 不自洽、历史长度不足、多标的时间错位。能整理的整理，可疑的记录下来，不机械删除真实的行情波动。
- 把取数和校验结果固定保存成内部快照（行情表 + 来源/时间/区间等元信息 + 质量报告）；用户无需预先选择快照。回测阶段只读已经解析好的快照，不再联网，保证同一次实验可复现。
- 无网络时可以生成一份明确标注"模拟数据"的快照用于开发测试，但不能和真实快照混淆。

数据模块已实现，接口与约定见 `core/data/` 各文件的 docstring。

**报告使用说明见 [docs/report.md](docs/report.md)。未配置模型时可查看完整图表和事实摘要。**

## 验收与测试

```bash
python -m pytest -q
python scripts/acceptance.py --live
# 或使用已有快照；回测、实验、报告阶段不联网
python scripts/acceptance.py --snapshot-id <snapshot_id>
```

`--live` 会先从行情接口获取真实快照；取数失败会报错，不替换为模拟数据。
验收脚本明确禁用模型调用，检查界面、数值一致性、全部图表、报告附件、证据问答不重复回测，
以及配置变化后的结果失效。
报告 ZIP 与验收 JSON 保存在 `artifacts/acceptance/`，默认不上传仓库。

## 数据来源与使用说明

ETF 历史日线数据来自公开接口（见 `core/data/sources.py`），复权口径为前复权。
数据能否随本仓库公开分发尚未核实，`data/snapshots/` 默认不提交原始数据，仅提交生成快照所需的代码。
