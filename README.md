#  量见

把自然语言策略想法和待验证的观点，转成可复现的历史实验，生成有证据、可追溯的分析报告。

> 历史回测不代表未来收益；测试未发现问题不等于策略已被证明有效。本项目仅供学习研究，不构成投资建议。

开发中（黑客松四天冲刺）。数据、双均线回测、自然语言解析和手动配置界面已完成，
自然语言界面接入、验证实验与证据报告仍待实现。详见下方「模块状态」。

## 快速开始

```bash
pip install -r requirements.txt
cp .env.example .env   # 填入大模型 API 配置（可选，未配置时 AI 解释环节会显式提示不可用）
streamlit run app.py
```

## 分工说明

**数据模块（`core/data/`，组员负责）**

- 定义本次支持的 ETF 资产池（标的代码、名称、所属类别），类别会影响质量检查的涨跌停阈值。
- 从公开接口拉取日线行情，统一列名和格式，取数失败要抛异常，不能静默返回空表或假数据。
- 对拉到的数据做质量检查：排序去重、缺失交易日、价格异常（只标记不删除）、非正价格、OHLC 不自洽、历史长度不足、多标的时间错位。能整理的整理，可疑的记录下来，不机械删除真实的行情波动。
- 把取数和校验结果固定保存成快照（行情表 + 来源/时间/区间等元信息 + 质量报告），回测阶段只读快照，不再联网，保证同一份快照每次回测结果一致。
- 无网络时可以生成一份明确标注"模拟数据"的快照用于开发测试，但不能和真实快照混淆。

这部分的函数签名和详细要求已经写在 `core/data/` 各文件的 docstring 里，可以直接按签名实现。

**自然语言解析模块已由组员完成；验证实验、报告生成和界面集成继续开发。**

## 数据来源与使用说明

ETF 历史日线数据来自公开接口（见 `core/data/sources.py`），复权口径为前复权。
数据能否随本仓库公开分发尚未核实，`data/snapshots/` 默认不提交原始数据，仅提交生成快照所需的代码。
