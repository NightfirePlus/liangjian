# 量见 · 测试版 0.1

把自然语言策略想法和待验证的观点，转成可复现的历史实验，生成有证据、可追溯的分析报告。

> 历史回测不代表未来收益；测试未发现问题不等于策略已被证明有效。本项目仅供学习研究，不构成投资建议。

## 项目状态

当前版本 `0.1.0`（测试版），已跑通真实行情和模拟行情的无 LLM 全流程：
手动配置双均线策略 → 回测 → 验证实验 → 图表与事实报告 → 证据附件下载。
自然语言界面接入、真实 LLM 联调、动量轮动及事件归因尚未纳入本版验收。
详见 [0.1 验收记录](docs/releases/0.1.md)。

## 快速开始

```bash
pip install -r requirements.txt
# 可选：在进程环境中设置 LLM_API_KEY、LLM_BASE_URL、LLM_MODEL（见 .env.example）
# 首次使用：生成模拟快照并执行无 LLM 完整验收；无需 API Key
python scripts/acceptance.py
streamlit run app.py
```

## 项目结构

```
core/
  schemas.py       共享数据契约（策略配置、快照、交易、指标、实验、证据引用）
  data/            数据获取、质量校验、快照管理
  backtest/        回测引擎、指标计算、基准
  experiments/     成本敏感性 / 参数邻域 / 分时段验证实验
  nlp/              自然语言解析、追问、策略确认卡
  report/          程序诊断 + 受证据约束的 AI 解释
app.py             Streamlit 入口
```

## 分工说明

**数据模块（`core/data/`，组员负责）**

- 定义本次支持的 ETF 资产池（标的代码、名称、所属类别），类别会影响质量检查的涨跌停阈值。
- 从公开接口拉取日线行情，统一列名和格式，取数失败要抛异常，不能静默返回空表或假数据。
- 对拉到的数据做质量检查：排序去重、缺失交易日、价格异常（只标记不删除）、非正价格、OHLC 不自洽、历史长度不足、多标的时间错位。能整理的整理，可疑的记录下来，不机械删除真实的行情波动。
- 把取数和校验结果固定保存成快照（行情表 + 来源/时间/区间等元信息 + 质量报告），回测阶段只读快照，不再联网，保证同一份快照每次回测结果一致。
- 无网络时可以生成一份明确标注"模拟数据"的快照用于开发测试，但不能和真实快照混淆。

这部分的函数签名和详细要求已经写在 `core/data/` 各文件的 docstring 里，可以直接按签名实现。

**报告使用说明见 [docs/report.md](docs/report.md)。未配置模型时可查看完整图表和事实摘要。**

## 验收与测试

```bash
python -m pytest -q
python scripts/acceptance.py --live
# 或使用已有快照；回测、实验、报告阶段不联网
python scripts/acceptance.py --snapshot-id <snapshot_id>
```

`--live` 会先从行情接口获取真实快照；取数失败会报错，不替换为模拟数据。
验收脚本明确禁用模型调用，检查界面、数值一致性、全部图表、报告附件和配置变化后的结果失效。
报告 ZIP 与验收 JSON 保存在 `artifacts/acceptance/`，默认不上传仓库。

## 数据来源与使用说明

ETF 历史日线数据来自公开接口（见 `core/data/sources.py`），复权口径为前复权。
数据能否随本仓库公开分发尚未核实，`data/snapshots/` 默认不提交原始数据，仅提交生成快照所需的代码。
