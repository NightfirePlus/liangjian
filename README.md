#  量见

把自然语言策略想法和待验证的观点，转成可复现的历史实验，生成有证据、可追溯的分析报告。

> 历史回测不代表未来收益；测试未发现问题不等于策略已被证明有效。本项目仅供学习研究，不构成投资建议。

## 项目状态

开发中（黑客松四天冲刺），当前为骨架阶段，大部分模块待实现。详见下方「模块状态」。

## 快速开始

```bash
pip install -r requirements.txt
cp .env.example .env   # 填入大模型 API 配置（可选，未配置时 AI 解释环节会显式提示不可用）
streamlit run app.py
```

## 项目结构

```
core/
  schemas.py       共享数据契约（策略配置、快照、交易、指标、实验、证据引用）
  data/            数据获取、质量校验、快照管理
  backtest/        回测引擎、指标计算、基准
  experiments/     成本敏感性 / 参数邻域 / 分时段验证实验
  nlp/              自然语言解析、追问、策略确认卡
  report/          程序诊断 + 受证据约束的 AI 解释
app.py             Streamlit 入口
```

## 模块状态

- [ ] 数据：接口获取、质量校验、快照保存与读取
- [ ] 回测：双均线、动量轮动，指标计算，基准对比
- [ ] 自然语言解析：策略提取、追问、确认卡
- [ ] 验证实验：成本敏感性、参数邻域、分时段
- [ ] 报告：程序诊断、AI 解释、证据可追溯

## 数据来源与使用说明

ETF 历史日线数据来自公开接口（见 `core/data/sources.py`），复权口径为前复权。
数据能否随本仓库公开分发尚未核实，`data/snapshots/` 默认不提交原始数据，仅提交生成快照所需的代码。

## 免责声明

本项目生成的所有回测结果、指标和分析仅基于历史数据与预设规则计算得出，不构成投资建议，不保证未来表现。
AI 解释部分受结构化事实约束，报告会明确区分已计算事实、程序诊断与尚未验证的推测。
