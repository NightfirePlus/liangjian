# 证据报告 v1

用户在 Agent 对话中确认策略后，Agent 连续执行回测、完整验证实验和报告生成，并在对话中显示进度。
热力图、对比图、结论、逐结论证据和下载文件统一展示在对话下方。
每条结论下展开证据；“下载报告与证据附件 ZIP”包含 Markdown、JSON、CSV 和离线 HTML 图表。
报告完成后可以继续在同一对话提问；回答不会重新运行实验，并附本次运行内的可展开证据附件。

## 面向新手的报告规划

本模块服务于“简单想法 → 可执行策略 → 历史验证 → 看懂结果”的产品路径，
详见 [产品定位与模块规划](product.md)。以下是后续呈现要求，尚未全部实现：

- 先用自然语言说明原始策略做了什么、与什么比较、实验观察到什么，再逐层展开指标和证据。
- 分开解释原始策略表现、参数变化、执行成本和市场时段差异，避免仅用总标签判定策略。
- 首次出现指标时给简短解释，例如超额收益是策略收益与比较基准收益的差值。
- 每条分析保留事实/解释区分与对应附件，默认值、样本限制和模拟数据标记可以查阅。
- 默认使用新手讲解，未来可切换为简洁摘要或技术细节；回答偏好不改变事实与重要限制。
- 支持直接追问当前报告，回答继续引用同次实验的证据；通用金融知识问答仍属于后续模块。

当前已验收事实报告、图表、导出和报告证据问答；回答模式设置、术语引导及跨模块
通用金融问答入口已提供基础概念解释；当前报告的具体追问仍在验证 Agent 中读取本次证据回答。
本页后续各节描述现有报告代码的技术约定。

## 模块职责

- `evidence.py`：从完整实验生成本次运行专属的证据 ID、内容哈希和统计。缺失值为 null；
  正超额收益比例的分母为有效结果数，同时保留计划数、缺失数和零成交样本数。
- `analysis.py`：提示词、只读工具循环、模型输出校验和离线事实报告。
- `qa.py`：报告追问、只读证据工具循环、回答校验和事实回退。
- `export.py`：保存正文及证据目录；Markdown 每条结论后链接对应附件。

完整实验不再自动输出“支持/不支持”的综合评级。旧 `ExperimentResult` 的规则字段仅用于
兼容单项实验调用；证据目录、模型输入和用户报告均不使用这些规则判断。

## 图表与口径

- 原始策略：净值、回撤；策略含成本，买入持有基准未扣成本。
- 参数邻域：超额收益热力图，星号标注原始参数；空白代表缺失/未测试，不填成零。
- 滑点：策略收益及超额收益折线，手续费保持原值。
- 时段：独立分段收益、超额收益与回撤柱状图，每段重新预热，不能直接相加。
- 交易：已平仓轮次的净盈亏分布、累计已实现盈亏。扣买卖两端成本；当前仅适用于
  单标的全仓进出。未平仓浮盈亏不计入，不能等同于净值曲线。

模拟数据标记、策略配置、比较基准、数据快照、质量问题和实验限制随证据一起保存。

## 模型协议

复用现有 `core.nlp.llm_client.complete_json` 及环境变量
`LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`。报告可用 `LLM_REPORT_MODEL` 单独选择更强的模型，
未设置时沿用 `LLM_MODEL`；可用 `LLM_TIMEOUT_SECONDS` 调整长报告请求的超时秒数。
本地启动时会自动读取仓库根目录的 `.env`；
进程环境变量优先于文件内容，`.env` 已被 Git 忽略，不应提交真实密钥。
可运行 `python scripts/llm_smoke.py --report` 检查接口连通、策略解析和四维度证据报告；
脚本只输出模型名与验证结果，不输出 API Key。
点击 AI 按钮后，实验摘要及模型请求的证据会发送到配置的模型服务。

v1 使用 JSON 工具请求协议，不要求服务商支持原生 function calling：

- `get_evidence(evidence_id)`：只读取当前证据目录。
- `get_parameter_cell(fast, slow)`：只查询已测参数表，不触发新实验。

最多四轮，每轮最多四次请求，每次网络调用沿用客户端的超时。模型初始输入包含实验配置、
快照/质量信息、全部实验摘要与三张实验表，可再查询逐日净值和成交数据。
服务不可用、协议错误、超出轮数或校验失败时回退为事实摘要，保留图表。

报告问答沿用同一证据目录和工具预算。回答中的数字也必须绑定证据字段；提到参数、成本或
时段实验时必须引用相应维度证据；回答原因类问题时必须引用逐日净值、交易往返或回撤/交易图表。
报告问答历史与策略输入历史分开保存，普通追问不会被带入下一次策略解析。

每条结论必须包含 dimension、title、level、statement_template、values、evidence_refs
与 limitations。四个实验维度必须全部覆盖；level 为 fact 或 diagnosis。
数字通过 `{v0}` 等占位符绑定到本条引用证据的字段路径，由程序格式化，模型不能在正文
直接输出阿拉伯数字。禁止跨运行引用、未知字段或任意代码/文件/网络工具。

## 校验的边界

程序可以检查证据归属、字段存在、数值来源和维度覆盖；这些检查不能证明一段自然语言
解释被证据充分支持。提示词限制事件因果判断、未来收益承诺及将比例误当置信度，但措辞
的语义正确性仍需结合附件审阅。图表自动附在相关维度之后，不代表图表证明了全部解释。
模型与提示词版本、工具调用记录、证据哈希一起导出，便于复核。

时事查询与归因仍未接入，`event_analysis` 继续预留为空。
