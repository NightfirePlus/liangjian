# 测试版 0.1（v0.1.0）

验收日期：2026-10-18。范围为无 LLM 的完整手动配置流程。

## 本版功能

- 行情取数、质量检查与可复用快照；可生成显著标识的模拟快照。
- 单标的双均线回测，次日开盘成交，包含配置的佣金和滑点。
- 滑点档位、参数邻域和真实时间区间实验。
- 净值、回撤、参数热力图、成本对比、分段对比及已平仓交易图表。
- 分维度事实报告、逐结论证据附件、Markdown/JSON/CSV/离线 HTML 的 ZIP 导出。
- 受约束 AI 报告接口已实现；此版本验收不调用实际模型。
